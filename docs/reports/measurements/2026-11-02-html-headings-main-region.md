# D2: страница без объявленного основного блока получает `<main>` — заголовки возвращаются

**Дата:** 02.11.2026
**Срез дерева:** `e07b580` + правка D2 (`_declare_main_region`, `trafilatura-html-5`)
**БД:** `~/.cohound/data/runs/ru-pg-dbms-1e0b04d6d83a/cohound.db` (read-only)
**Выборка:** 40 страниц на host, детерминированная равномерная по отсортированным URL
**Инструмент:** `scripts/measure_html_extraction.py` (метрики приёмки), извлечение — штатный
`core.adapters.extract_html.HtmlExtractor`

## Итог одной строкой

`trafilatura` ищет статью **по контейнеру**; у DocBook-вёрстки его нет, поэтому правило не
срабатывает и извлечение уходит плоским путём — `<h2>` приезжают простым текстом, каркас
тоже. Объявление тела документа основным блоком (`<main>`) возвращает заголовки на трёх
хостах из шести (**0.000 → 0.845**, **0.024 → 0.939**, **0.000 → 0.782**), а на остальных
не меняет **ни одного знака**.

## Механизм (измерен, а не предположен)

Синтетическая страница с одним и тем же содержимым (`<h1>`, `<p>`, `<h2>`, `<p>`), меняется
только контейнер:

| контейнер | ATX-заголовков в извлечении |
|---|---|
| голый `div`, `div.container`, `section` | **0** |
| `main`, `article`, `[role=main]`, `[itemprop=articleBody]`, `#content`, `.post` | **2** |

То есть дело не в настройках и не в нашей чистке: `trafilatura` 2.3.1 на странице **без**
распознанного контейнера извлекает текст плоским путём, где `<h*>` — обычный абзац. Проверено
и обратное: `favor_recall`, `favor_precision`, `include_formatting=True`, `fast=True` на
реальном diasoft-документе дают **0** ATX во всех вариантах.

Настоящая вёрстка (`database.diasoft.ru`, страница `sql-dropschema`): заголовки живут в
`div.container > div.doscList > div.refentry > div.refsect1 > h2`, контейнера статьи нет.
Извлечение начиналось с cookie-баннера, а «Описание»/«Параметры» шли текстом без `#`.

## Почему diasoft 0.845, а не 1.000

Метрика считает **все** `<h1..h6>` документа, включая каркас. На diasoft это:

- `h1.nameSite` «ДОКУМЕНТАЦИЯ» — заголовок шапки сайта (на каждой странице);
- заголовки блоков навигации/примечаний (`div.note > h3`), которых в статье нет.

Это ровно те заголовки, которых в тексте быть не должно. Остаток 15.5 % — цена того, что
знаменатель метрики не отделяет статью от chrome (см. «Чего числа не доказывают»).

## Отвергнутый вариант (и его число)

Рассматривалось восстановление заголовков **после** извлечения: пометить ATX-маркером строки,
чьи тексты совпали с заголовками DOM в порядке документа. Замер на том же diasoft: `kept`
**0.015**. Причина: в плоском пути текст заголовка не остаётся отдельной строкой (он склеен с
соседним абзацем), помечать нечего. Подход отвергнут по числу, а не по вкусу.

## Чего числа не доказывают

- `edu.postgrespro.ru`: `chrome_share` 0.767 → 0.802 и рост длины на 10 % — страницы уроков
  подтягивают больше содержимого; `body_coverage` остаётся 1.000, то есть «основной блок»
  извлечён целиком и в обоих случаях, но состав текста вне его стал другим.
- `tantorlabs.ru`: длина +40 % и `body_coverage` 0.447 → 0.555 — извлекается больше текста
  (часть — то, что метрика относит к каркасу), `chrome_share` 0.000 → 0.001.
- Малые выборки, где направление смешанное: `jatoba.ru` (1 страница) `kept` 0.700 → 0.900 при
  `chrome_share` 0.005 → 0.088; `www.gaz-is.ru` (2 страницы) `kept` 0.500 → 0.667 при
  `body_coverage` 0.324 → 0.254. Ориентир, не вывод.
- `headings_kept` — **нижняя** оценка (сравнение по префиксу первых 40 символов).
- «Основной блок» метрики — первый `article|main|[role=main]`, иначе самый длинный
  `div|section`; на diasoft в него попадает cookie-баннер, поэтому `body_coverage` там не
  абсолютная величина.

## Цена правки

- Версия читателя: `trafilatura-html-4` → **`trafilatura-html-5`**. Это `execution_change`:
  текст корпуса меняется ⇒ новый `run_id` у пакетов с затронутыми хостами, новые ключи
  `extract_cache`, пере-краул обязателен. `embed_cache` не помогает: ключ — хеш текста чанка.
- Стоимость на документ: один дополнительный разбор lxml **только** для страниц без маркера
  (у страниц с маркером — разбор и ранний возврат того же объекта, без сериализации).
- Регулярное выражение/селектор маркера — объявление HTML-семантики (`article`, `main`,
  `role`, `itemprop`, `#content`), а не список сайтов: `core/` остаётся нейтральным.
