# Замеры — доказательства в дереве

Здесь лежат **маленькие** артефакты замеров, на которые ссылаются архитектурные
документы: JSON, текст, CSV, короткие логи. Правило введено после аудита документации
2026-10-23: `docs/architecture/06-implementation-strategy.md` ссылался на
`runs/ru-pg-dbms-fixation` и индексную сборку `ib_8923…` как на доказательство «фиксация
выполнена», а ни того, ни другого в дереве не было и быть не могло — `runs/` и
`index_store/` в `.gitignore`. Доказательство, живущее только пока жив каталог, — не
доказательство.

## Правило

1. **Архитектурный документ не ссылается на `runs/*` или `index_store/*` как на
   доказательство.** Вместо ссылки — команда, её параметры и результат (или файл здесь).
2. Маленький результат замера (до ~100 КБ) кладётся сюда и коммитится.
3. Крупные данные не коммитятся. Вместо них — здесь файл с командой, параметрами,
   агрегатами и датой; сырьё воспроизводимо командой.
4. У каждого файла в шапке или в имени — **дата** и **срез дерева** (коммит), иначе замер
   невозможно привязать к коду.
5. Замер без условий (что запускали, на каком дереве, сколько памяти/времени) — не замер,
   а мнение (A3: замена дефолта происходит по измерению, не по предвидению).
