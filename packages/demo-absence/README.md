# demo-absence — демонстрационный **стенд**, не кейс

Не продуктовая карта и не прогон для публикации: четыре параметра, одна страница вендора,
ни одной ячейки, выведенной наследованием (архетип B, `baselines: []`).

Текст — Tantor SE 18.6, «29.8. Ограничения»:
<https://docs.tantorlabs.ru/tdb/ru/18_6/se/logical-replication-restrictions.html>
(прочитано 05.11.2026; вендор дословно перечисляет отсутствующие возможности).

Зачем: замер правила I2d (план 20 §11) — «`❌` требует датированного носителя наблюдения
в этом цикле». Стенд даёт страту `explicit`-отрицаний, которой в пилоте `ru-pg-dbms` нет
(все 181 параметра `explicit`, но ни один не совпал с текстом вендора).

Пакет не участвует ни в одной публикации: `case_class` golden — `class_absent`,
`snapshot_date 2026-11-05`, прогоны живут только на изолированном стенде.
